# ABYSS · 深海生态观测站

一个跑在浏览器里的深海生态 3D 模拟器。41 个深海物种、820 米垂直落差，鼠标键盘自由穿行于海山侧翼。

**直接打开就能玩：** https://dzry1415926-arch.github.io/abyss-3d/

## 玩法

| 操作 | 键位 |
|---|---|
| 移动 | `W` `A` `S` `D` |
| 上浮 / 下潜 | `Space` / `C` |
| 探照灯 | `F` |
| 深海图鉴 | `L` |
| 观察标本 | 点击生物 |
| 视角 | 按住鼠标拖拽（或用方向键） |

触屏设备会自动切换为横屏 + 虚拟摇杆模式。

## 内容

- **41 个深海物种** — 从 300 米的中层带发光鱼类，到 1120 米热泉口的管虫群落
- **完整 PBR 材质** — 每个模型都重新烘焙了基础色、法线、粗糙度、自发光四张贴图
- **生物发光** — 鮟鱇的诱饵、灯笼鱼的腹侧发光器、水母的荧光胶质层
- **可控探照灯** — 光锥会随深度衰减，越往下越暗
- **标本图鉴** — 点击任意生物查看学名、栖息深度、形态特征

## 技术

纯前端，无构建步骤，无后端依赖：

- **three.js** — WebGL 渲染
- **单文件交付** — 全部资源内联，`file://` 双击也能跑
- **GLB 模型** — 41 个，总计约 24MB，按需加载

## 本地运行

因为模型通过 `fetch` 加载，需要起一个静态服务器（直接双击 `index.html` 会被浏览器跨域策略拦截）：

```bash
# Python
python3 -m http.server 8000

# 或 Node
npx serve .
```

然后打开 http://localhost:8000
